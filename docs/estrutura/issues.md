# `issues/` — pendências do framework

## Para que serve

Notas e checklists **internos** sobre o próprio Spoiler (dívidas técnicas, ideias, pendências do fork) — não é o board Jira/Linear do time de produto.

## Conteúdo atual

| Arquivo | Uso |
|---------|-----|
| `spoiler-pendencias.md` | Lista de pendências / ideias relacionadas ao framework |

## O que não é

- Não substitui GitHub Issues do repo ([phelipperibeiro/spoiler](https://github.com/phelipperibeiro/spoiler/issues))
- Não é lido automaticamente pelos workflows de engenharia do produto
- Para reportar bug do framework pelo chat: skill `report-issue` (usa `SPOILER_PROJECT` no ENV)

## Pacote npm

`issues/` **não** entra no tarball publicado e **não** é copiado no `spoiler init`.
